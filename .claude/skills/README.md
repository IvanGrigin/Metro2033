# Скиллы сценариста

Здесь лежит часть набора [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills)
(коммит `51115f1`, MIT; условия в `LICENSE` и `NOTICE` внутри каждой папки).
Мы скопировали их в репозиторий, чтобы облачные сессии Claude Code видели их без установки.

Для адаптации романа в полнометражный фильм используются:

| Скилл | Зачем |
|---|---|
| `sw-workflow` | Порядок этапов и файл состояния `story-bible.md` |
| `sw-format-adaptation` | Четыре вопроса адаптации, формат страницы, вывод в Fountain |
| `sw-premise-theme` | Предпосылка, управляющая идея, логлайн |
| `sw-story-structure` | Три акта, BS2, диагностика структуры |
| `sw-character-conflict` | Персонажи, антагонист, арка |
| `sw-scene-craft` | Поэпизодный план, ценностный поворот сцены |
| `sw-dialogue` | Диалоги и их диагностика |
| `sw-genre-anatomy`, `sw-truby-anatomy` | Жанровые биты (хоррор / миф / фантастика), органическая проверка |

Тексты скиллов написаны по-китайски, но отвечают на языке вопроса.
