## 2. Чек-лист по слоям

### B. Реальное место (заполняется один раз на место)

- [ ] Линия, соседи по линии в обе стороны (порядок станций — по схеме, не по памяти)
- [ ] Тип: пилонная / колонная / колонно-стеновая / однопролётная (односводчатая); число сводов
- [ ] Заложение: глубокое / мелкое, глубина в метрах
- [ ] Платформа: островная / береговые, длина, ширина
- [ ] Свод и потолок: форма, высота, светильники
- [ ] Отделка: материалы и цвета по фото (стены путей, пол, колонны)
- [ ] Выходы: сколько вестибюлей, с какого торца, эскалатор / лестница, длина эскалатора
- [ ] Вестибюль: тип (наземный павильон, ротонда, встроенный в здание, подземный переход), что вокруг на поверхности
- [ ] Переходы на другие линии: из какой части зала
- [ ] Служебные помещения: где (торцы, за путевыми стенами)
- [ ] Путевое развитие с обеих сторон: тупики, оборотные пути, перекрёстные съезды, соединительные ветки, камеры съездов — с привязкой к расстоянию от станции
- [ ] Боковые и служебные туннели, если их называет сценарий или роман

### C. 2033 год

- [ ] Кто владеет станцией, сколько жителей
- [ ] Свет: электричество / аварийный красный / костры / нет света; меняется ли «ночью»
- [ ] Что на платформе (палатки, лавки, фермы), что на путях
- [ ] Укрепления: кордоны, мешки, пулемёты — где именно (в зале, в туннеле, на каком метре)
- [ ] Разрушения: обвалы, затопление, гермозатворы — открыты/закрыты
- [ ] Для флэшбеков: что из этого уже было N лет назад, а чего ещё не было

### D. Геометрия кадра

- [ ] Тип зала совпадает с паспортом
- [ ] Пропорции: длина/ширина/высота по человеку 1,75 м
- [ ] Ряд колонн/пилонов: шаг, сечение, число рядов
- [ ] Туннель: Ø около 5,1 м (чугунные кольца, шаг колец), рельсы, контактный рельс, кабели на стенах
- [ ] На этом пикете туннель именно однопутный, без съезда — сверено со схемой путевого развития
- [ ] Выходы, торцы, двери стоят там, где в паспорте
- [ ] Небо/поверхность в «НАТ.» сценах: что видно сквозь проём — соответствует месту на поверхности

### E. Состояние сцены

- [ ] Время суток сцены → свет станции. Пары «день/ночь» одного места сравнить рядом
- [ ] Часы (если в кадре) показывают время из листа требований; если время не названо — не противоречат сюжету
- [ ] Надписи и цифры на стенах — тот же текст, то же место («250» на стене, «300» на столбе)
- [ ] Огонь/костёр/фонарь есть, если назван, и является источником света в кадре
- [ ] Тревога/пожар/красный аварийный свет — включены только в нужных сценах

### F. Непрерывность

- [ ] Одно место — одна геометрия во всех сценах
- [ ] Постоянный реквизит на тех же местах (палатки, стол, часы над туннелем)
- [ ] То, что сюжет изменил (ушедший гость, пустая палатка), изменилось
- [ ] Флэшбек не содержит поздних деталей

### G. Позы

- [ ] Ключевое действие ремарки читается (объятие, удар, наклон над картой, взгляд назад)
- [ ] Число людей соответствует тексту и населению места
- [ ] Возраст персонажа в флэшбеке (Артём 5 / 8 лет)
