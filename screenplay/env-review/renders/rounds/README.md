# Все круги рендеров

Каждый круг — снимок папки `renders/` на коммите, которым постановщик сдал круг. Ничего не перезаписывается: новый круг кладётся новой папкой, `renders/` наверху — всегда текущий.

| `r2-2026-10-15` | `64af4ec` | второй прогон по сводке (3, 7, 8, 12–14, 16–20, 22, 24) | `2026-10-15-round2-regression.md` |

| `r4-2026-10-16` | `cceead6` | плоские превью всех 377 планов, код всех сцен | `2026-10-16-round4-*.md`, `preview-*.md` |
| `r5-2026-10-16` | `9e9d4a5` | превью после правок критика, обзоры 14 мест | `2026-10-16-round5-*.md` |

Файлы, которые не менялись между кругами, git хранит один раз — папки почти не увеличивают репозиторий.

Вне репозитория (у постановщика): кадры по секундам, `.blend`, видео — пересобираются из `src/` этого же круга; референсы из Steam — в публичный репозиторий нельзя.
