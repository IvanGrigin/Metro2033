## .blend и видео

С r6 у каждого круга есть `blend/` (24 сцены, около 142 МБ, файлы до 21 МБ; текстур нет). Для старых кругов сохранилось только состояние последнего полного рендера 15.10 — оно лежит в `r3-2026-10-15/blend/` и `r3-2026-10-15/video/` (сцены 1, 4, 6, 15 — по r3, остальные — по r2). `.blend` кругов r1, r4, r5 перезаписаны и не сохранились; при необходимости их можно пересобрать из `src/` своей папки (`run_scene.py`).

Кадры по секундам не хранятся (решение пользователя 16.10): они пересобираются из `.blend`.

Вне репозитория (у постановщика): кадры по секундам, `.blend`, видео — пересобираются из `src/` этого же круга; референсы из Steam — в публичный репозиторий нельзя.
