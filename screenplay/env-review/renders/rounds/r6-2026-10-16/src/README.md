# 3D-превиз «Метро 2033»

Упрощённые 3D-сцены — каркас для каждого кадра: геометрия, свет, расстановка и движение персонажей. Нейросеть (Codex) потом «одевает» кадр, не меняя ни ракурса, ни расстановки.

## Устройство

| Файл | Что делает |
|---|---|
| `lib/kit.py` | Общая библиотека: материалы с «плоскими» цветами, предметы (кружка с одной ручкой, АК, ящик), шарнирные манекены с позами и ходьбой, камеры, проходы рендера |
| `lib/locations.py` | Локации кодом. Одна функция — одна локация; одна и та же функция всегда даёт одну и ту же геометрию, поэтому все сцены и камеры в локации согласованы |
| `scenes/sNNN.block.json` | То, что решает человек: локация, состав, ящики, предметы, свет, события, имена из EN-промтов → id персонажей, ручные камеры для отдельных планов |
| `scenes/sNNN.json` | Полная сцена для рендера: собирается из `.block.json` и раскадровки командой `tools/make_scene.py` |
| `WORLD.md` | Справочник реального метро и мира «Метро 2033» с источниками: размеры станций, отделка, население |
| `run_scene.py` | Собирает сцену, анимирует, рендерит |
| `out/sNNN/` | Результат: `stills/`, `animatic/`, `sNNN.blend` (можно открыть в Blender и поправить руками) |

## Запуск

```bash
python3 storyboard/tools/make_scene.py storyboard/3d/scenes/s004.block.json
blender -b -P storyboard/3d/run_scene.py -- storyboard/3d/scenes/s004.json storyboard/3d/out/s004 --preview
python3 storyboard/tools/preview_sheet.py storyboard/3d/out/s004/preview /tmp/s004.png
blender -b -P storyboard/3d/tools_location_preview.py -- /tmp/locs vdnkh,botanical
blender -b -P storyboard/3d/run_scene.py -- storyboard/3d/scenes/s001.json storyboard/3d/out/s001
python3 storyboard/tools/make_tasks.py storyboard/3d/scenes/s001.json
```

`--preview` — только плоский первый кадр каждого плана, за минуту: проверить камеры. Без флагов — полные кадры и аниматик. `--shots 1.05,1.12` — только эти планы. `make_tasks.py` создаёт задачи для Codex в `exchange/tasks/`.

## Проходы рендера (на первый кадр плана, каждую целую секунду и последний кадр)

| Файл | Что это | Зачем |
|---|---|---|
| `*_lit.png` | Свет сцены (костёр, фонари), EEVEE | Каким должен быть свет |
| `*_flat.png` | Плоские цвета при ровном свете, с тенями и кавити | Геометрия читается даже там, где в `lit` темно |
| `*_id.png` | Только люди своими цветами, всё остальное серое | Кто где в кадре |
| `*_depth.png` | Глубина: ближе — темнее | Для контроля перспективы и видеомоделей |

Цвета персонажей: Артём — синий, Пётр — оранжевый, Андрей — зелёный, Кирилл — жёлтый, Хантер — красный, Сухой — фиолетовый. Белый конус на голове — нос: лицо смотрит туда.

## Сцена в JSON

- Время берётся из длительностей планов (`shots[].dur`). Событие привязано к началу плана: `"at": "1.11", "dt": 0.5`.
- События: `place`, `pose`, `walk`, `turn`, `look`, `move` (скольжение без шагов: дрезина, ребёнок на руках), `show`/`hide` (предмет или персонаж), `light`, `prop_move` и `prop_scale` (едет дрезина, растекается поток крыс).
- Высота пола: на платформе станции люди и ящики стоят на z = 1,1 — `pos: [x, y, 1.1]`, ящик `[x, y, facing, 1.1]`.
- Предметы: `mug`, `rifle` (через `"rifle": true` у персонажа), `crate`, `handcar`, `sandbags`, `machine_gun`, `searchlight`, `flame_jet`, `rat_flood`, `puppy`, `shotgun`, `lantern`, `muzzle_flash` (вспышка выстрела со светом), `block` (любой размер и цвет — рюкзак, книги, скамья).
- Фонарь или прожектор в руке (`attach` на `Имя.hand_R`/`hand_L`) светит вдоль руки: включённый фонарь держат позами `flashlight`/`hold_light`. В воздухе всех подземных локаций лёгкая дымка, поэтому лучи видны; на улице (`botanical_vestibule`) дымки нет — в EEVEE она закрыла бы небо.
- Порталы станций открыты: за каждым путевым порталом 30 м настоящего тоннеля (можно снимать въезд и отъезд). Чайная фабрика ВДНХ отделена от главной улицы брезентовой перегородкой 2,4 м с широким проходом.
- `show` персонажа не открывает скрытые предметы у него в руках — их показывают отдельным `show` предмета.
- ВДНХ: фоновые жители добавляются сами (60 днём, 12 при `light_scale` < 1), держатся в 1,5 м от мест актёров и ящиков; `"crowd": N` в блокинге меняет число.
- Роли (цвет в раскраске): главные по имени; остальные через `"role"`: Mother, ArtyomChild, Black, Extra, Zhenya, Vitalik, Commander, Nikita, Alexander, OldWorker.
- Позы: `stand`, `stand_rifle`, `aim`, `sit`, `sit_rifle`, `sit_feed`, `sit_pour`, `sit_mug`, `offer`, `flashlight`, `hold_light`, `carry_child`, `sit_carry`, `reach_out`, `prone`, `fallen`, `kneel_up`, `floor_ears`, `flame` (`lib/kit.py`, `POSES`).
- Камера по умолчанию строится сама из раскадровки (`make_scene.py`): крупность из заголовка плана (крупный, средний, общий, деталь, через плечо, точка зрения, тьма), персонаж — первое имя в EN-строке, «со спины», нижний/верхний ракурс, наезд/отъезд. Камера ставится перед персонажем с учётом, куда он смотрит, остаётся внутри стен локации и обходит перекрытия (перебирает углы). Ручная камера для плана — в `cams` файла `.block.json`.
- Ручная камера: `pos` + `at` (точка или `"Артист.сустав"`, например `"Pyotr.eyes"`), `lens` в мм. Вместо `pos` можно `rel` — направление от цели; расстояние тогда считается само из крупности (`size`: 0,65 м — крупный, 1,5 м — средний). `push` — наезд (минус — отъезд).
- Оси: +Y — север (тьма), Z — вверх, пол на z = 0. Направление `facing` — градусы по часовой от севера.

## Локации

Готовы: `tunnel_250`, `north_cordon`, `peregon_savelovskaya`, `timiryazevskaya`, `vdnkh` (с «Главной улицей», гостевой палаткой, часами и чайной фабрикой), `botanical` (с гермозатвором и эскалатором), `botanical_vestibule`, `sukhoi_tent`, `vdnkh_office`, `white_room`. Станции строятся типовой функцией `station(kind=...)` по реальным размерам из `WORLD.md`: пилонная, однопролётная, колонная. Новая сцена в готовой локации — это только новый `.block.json`.

Качество — 90%, а не 100%: пространство, свет, расстановка и камеры должны читаться; мелкие детали не доводятся.
